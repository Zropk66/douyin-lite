douyin_lite 使用说明
====================

简介
----
抖音 PC 客户端低内存运行器。通过进程注入与 API Hook，将刷视频时 1.5GB+ 的内存占用
稳定控制在 700MB 以内。不修改抖音安装目录的任何文件。

文件说明
--------
douyin_lite.dll    核心 Hook 模块（必须）
douyin_lite.exe    启动注入器（必须）
douyin_lite.ini    内存参数配置（可选，删除后首次运行会自动生成默认配置）
LICENSE            开源协议

使用方法
--------
方式一：将 douyin_lite.dll 与 douyin_lite.exe 复制到抖音安装目录
（与 douyin.exe 同级），双击 douyin_lite.exe。

方式二：放到任意目录，通过命令行参数指定抖音路径：

    douyin_lite.exe --exe "D:\Program Files (x86)\ByteDance\douyin\douyin.exe"

命令行参数
----------
--exe <路径>    目标程序路径，缺省为当前目录下的 douyin.exe
--dll <路径>    注入模块路径，缺省为当前目录下的 douyin_lite.dll
--help          显示用法

抖音已在运行时再次启动 douyin_lite.exe，会将现有主窗口唤起到前台，不会重复注入。

配置项（douyin_lite.ini）
-------------------------
[mem]
v8_heap_mb=512
renderer_limit=4
total_threshold_mb=900
single_threshold_mb=400
trim_target_mb=300
cooldown_sec=6

各字段含义与调整方法：

v8_heap_mb              单个渲染进程 V8 JS 堆上限。调低可压 JS 对象内存，
                        过低会导致复杂页面卡顿或崩溃，建议不低于 256
renderer_limit=4        渲染进程数量上限。调低减少进程冗余内存，
                        但单进程承担更多页面，内存集中且峰值更明显
total_threshold_mb=900  整棵进程树物理内存熔断阈值。树内存超过此值立即触发
                        全树修剪，是实际内存上限的主开关；越高常驻内存越高
single_threshold_mb=400 单进程物理内存熔断阈值。任一进程超过此值触发修剪；
                        调低可更早压制内存大户
trim_target_mb=300      触发修剪后单进程工作集压到的目标值。
                        内存与 CPU 平衡的核心旋钮：越大内存越高 CPU 越平稳，
                        越小内存越低 CPU 波动越明显
cooldown_sec=6          两次修剪的最小间隔。过小会频繁修剪造成缺页风暴
                        抬高 CPU，过大则内存峰值持续更久

修剪触发后的内存走向：各进程工作集被压向 trim_target_mb，随后随使用回升，
触及 total_threshold_mb 或 single_threshold_mb 时再次修剪，循环往复，
实际内存稳定在这组阈值划定的区间内。

内存与 CPU 占用的平衡规律：给内存的预算越多，CPU 波动越小。
压缩内存的代价是冷页被挤掉后再次使用需重新读入（软缺页），CPU 波动即来源于此。
波动为瞬时性质，正常观看单个视频不受影响：

- 波动发生在下滑加载新视频的瞬间
- 想要 CPU 更平稳：调大 trim_target_mb（如 300 → 500），并同步上调
  total_threshold_mb 与 single_threshold_mb
- 想要内存更低：调小 trim_target_mb（如 300 → 200），并同步下调
  total_threshold_mb（如 900 → 600）与 single_threshold_mb（如 400 → 250）
- 保持默认值即可，默认配置在内存与 CPU 间取了平衡

修改后重启抖音生效。数值越界或不合法时自动回落内置默认值。

已知代价
--------
- 向回翻看历史视频时缓存已被释放，需重新加载。
- 窗口失焦一段时间后切回可能出现一次极短的顿挫（软缺页）。
- 修剪后内存重新回升属正常现象：回升越快说明正在消费冷缓存，达阈值会再次收缩。
- 下滑加载新视频瞬间 CPU 占用有概率短时波动增大，正常观看不受影响。

卸载
----
直接删除 douyin_lite.dll、douyin_lite.exe、douyin_lite.ini 即可，
抖音恢复原版行为。
